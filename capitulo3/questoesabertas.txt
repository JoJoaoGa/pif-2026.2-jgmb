#Questão 01. Diferenças Fundamentais e Tempo de Avaliação de Laços

a. No "while", a condição de teste é avaliada no início, antes da execução do bloco. No "do-while" a condição é avaliada no final, após a execução do bloco.
O laço "while" pode não ser executado nenhuma vez caso a condição seja falsa logo no primeiro teste. E o "do-while" executa no mínimo 1 vez, pois o bloco de código é processado antes da primeira checagem.

b. O "for" é utilizado quando o número de iterações é previamente conhecido ou fixo, como contagens definidas ou percorrimento de vetores/matrizes.
O "while" é mais adequado quando não se sabe quantas vezes o laço irá se repetir, e a verificação deve ocorrer antes de iniciar o processo, como na leitura de arquivos até o final ou aguardar uma alteração de estado do sistema.
O "do-while" é ideal quando o bloco precisa ser executado ao menos uma vez, como para menus interativos e validação de entrada de dados fornecida pelo usuário.

c. É um erro de lógica, pois o ponto e vírgula representa uma instrução nula. Se condição for verdadeira, o programa entrará em um loop eterno, executando repetidamente uma instrução nula. Como o corpo vazio, o valor da variável não será alterado, travando a execução do programa nessa linha.


#Questão 02. Escopo e Tempo de Vida de Variáveis de Bloco

a. Um erro de compilação por declaração/sintaxe porque a variável "soma" foi declarada localmente no bloco do `for`.

b. O "int soma = 0;" está dentro do for, a variável "soma" é reinicializada com a cada iteração, ela não vai acumular os valores das iterações.

c.
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0; // Declarada no escopo da função main para acumular os valores

    for (i = 1; i < 10; i++) {
        soma += i * i;
    }

    printf("Soma final = %d\n", soma);
    system("PAUSE");
    return 0;
}

Visibilidade refere-se à região do código em que o nome de uma variável pode ser acessado.
Escopo do bloco limita a visibilidade de uma variável às instruções contidas entre o par de chaves onde foi declarada.
Tempo de Vida é o período de execução do programa no qual a memória atribuída à variável permanece alocada.

#Questão 04. Comandos de Desvio de Fluxo: break vs. continue

a. O "break" interrompe a execução do laço em que está contido, passando o fluxo do código para a primeira instrução após o fechamento do laço.

b. O "continue" encerra antecipadamente apenas a iteração atual, ignorando instruções restantes do laço e saltando para o final do corpo.

c. Em laços aninhados, o "break" interrompe apenas o laço interno em que foi executado. O laço externo continua seu ciclo normalmente.
